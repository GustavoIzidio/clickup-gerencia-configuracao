# Requisitos analisados

## Requisitos Funcionais

### RF01 - Criar tarefas
O sistema deve permitir que o usuário crie tarefas para registrar atividades.

### RF02 - Definir prioridade
O sistema deve permitir associar uma prioridade às tarefas.

### RF03 - Alterar status
O sistema deve permitir acompanhar e alterar o status das tarefas.

### RF04 - Visualizar tarefas
O sistema deve permitir visualizar as tarefas utilizando diferentes formas de organização.

### RF05 - Filtrar tarefas
O sistema deve permitir filtrar tarefas de acordo com critérios disponíveis.

### RF06 - Associar responsáveis
O sistema deve permitir identificar os responsáveis pelas tarefas.

## Requisitos Não Funcionais

### RNF01 - Organização
As informações devem ser apresentadas de forma organizada para facilitar o acompanhamento das atividades.

### RNF02 - Rastreabilidade
As alterações realizadas no projeto devem ser registradas por meio do sistema de controle de versão.

### RNF03 - Controle de versões
Os artefatos do projeto devem ser mantidos em um repositório Git.

### RNF04 - Documentação
As principais informações do projeto devem estar documentadas e versionadas.
