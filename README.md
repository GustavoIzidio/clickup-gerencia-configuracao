# Gerência de Configuração - ClickUp

## Nome do sistema
ClickUp

## Objetivo do sistema
O ClickUp é uma plataforma de gerenciamento de tarefas, projetos e atividades de equipes. Neste projeto, o sistema será analisado para aplicar conceitos de Gerência de Configuração e controle de versões.

## Principais funcionalidades
Entre as principais funcionalidades analisadas no ClickUp estão:

* Criação e gerenciamento de tarefas;
* Organização das tarefas por diferentes visualizações;
* Definição de prioridades;
* Acompanhamento do status das atividades;
* Utilização de filtros e ordenação;
* Organização das atividades em projetos e equipes;
* Criação de dependências entre tarefas.
